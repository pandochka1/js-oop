Теория

Что такое массив объектов learn.javascript.ru/object

Мы уже знаем два инструмента: массив хранит набор однотипных значений, объект — набор полей с именами. Реальная логика очень часто требует совместить их: хранить несколько записей с одинаковым набором полей. Для этого служит массив объектов.

Представьте таблицу: строки — это записи, столбцы — поля. Массив объектов — «таблица», где каждая строка (объект) имеет одни и те же столбцы (поля):

let users = [
  { name: "Олег", age: 21, role: "user" },
  { name: "Мария", age: 30, role: "admin" },
  { name: "Пётр", age: 17, role: "user" }
];

Снаружи квадратные скобки — массив. Внутри, между фигурными скобками каждой записи, — объект с полями. Обращение к полю конкретной записи — двойное: сначала по индексу массива, затем по имени поля через точку.

users[0].name;   // "Олег" — первая запись, поле name
users[1].role;   // "admin" — вторая запись, поле role

Ничего нового в этом нет: это уже знакомые записи массива и обращение к полям объектов, соединённые вместе.

Кибербезопасность
Массив объектов — естественная модель для данных ИБ: список пользователей системы, журнал событий, записи о сетевых соединениях. Поля записей в точности соответствуют столбцам логов, которые собирает SIEM.
Создание и запись в массив объектов

Массив объектов можно объявить сразу значениями или заполнять постепенно:

let events = [];

events.push({ source: "192.168.1.1", level: "warn", code: 403 });
events.push({ source: "10.0.0.5", level: "info", code: 200 });
events.push({ source: "192.168.1.1", level: "error", code: 500 });

console.log(events[2].source); // 192.168.1.1
console.log(events[1].code);   // 200

Каждый push добавляет новую запись в конец. Так строится «живой» журнал, который наполняется по мере работы.

Поле существующей записи можно изменить или добавить:

events[0].code = 403;          // изменить существующее поле
events[0].handled = false;      // добавить новое поле

Поскольку массив — это ссылочный тип, добавление во вложенный объект работает через общий массив.

Перебор массива объектов

Перебор массива объектов ничем не отличается от перебора обычных чисел — цикл for с индексом, только внутри мы работаем с объектом по индексу:

let users = [
  { name: "Олег", age: 21 },
  { name: "Мария", age: 30 }
];

for (let i = 0; i < users.length; i++) {
  console.log(users[i].name + " — " + users[i].age);
}

Внутри цикла users[i] — это объект, поэтому к его полям обращаемся через точку: users[i].name, users[i].age.

Такой обход — база для всех дальнейших операций: поиска по полю, фильтрации, подсчёта значений, сортировки. Любимый приём — накопление результата в отдельной переменной, как и с массивами чисел.

Поиск и фильтрация по полю

Поиск записи по значению поля повторяет алгоритм поиска в массиве, только сравниваем мы не весь элемент, а его поле:

let found = -1;
for (let i = 0; i < users.length; i++) {
  if (users[i].name === "Мария") {
    found = i;
    break;
  }
}

Фильтрация строит новый массив, в который попадают записи, удовлетворяющие условию по полю:

let adults = [];
for (let i = 0; i < users.length; i++) {
  if (users[i].age >= 18) {
    adults.push(users[i]);
  }
}

Условие можно строить по любому полю и комбинировать поля, связывая проверки логическими операторами из темы про условия.

Сортировка массива объектов по полю

Сортировка объектов выполняется тем же способом, что и чисел, но сравнение идёт по одному полю. Возьмём сортировку пузырьком, где обмениваются местами целые записи, если их поля стоят в неправильном порядке:

let users = [
  { name: "Олег", age: 21 },
  { name: "Мария", age: 30 },
  { name: "Пётр", age: 17 }
];

for (let i = 0; i < users.length - 1; i++) {
  for (let j = 0; j < users.length - 1 - i; j++) {
    if (users[j].age > users[j + 1].age) {
      let temp = users[j];
      users[j] = users[j + 1];
      users[j + 1] = temp;
    }
  }
}

// Теперь порядок по возрасту: Пётр(17), Олег(21), Мария(30)

Ключевая строка — условие users[j].age > users[j + 1].age: сравниваются именно поля age. Меняются целиком объекты, а не только числа. Чтобы сортировать по другому полю, достаточно заменить age на нужное имя.

Агрегация значений поля

Когда нужно посчитать что-то по всем записям — сумму, среднее, минимум, максимум — берут одно поле и накапливают результат:

let users = [
  { name: "Олег", score: 85 },
  { name: "Мария", score: 92 },
  { name: "Пётр", score: 78 }
];

let sum = 0;
for (let i = 0; i < users.length; i++) {
  sum += users[i].score;
}

console.log(sum);           // 255
console.log(sum / users.length); // 85 — среднее

Так же вычисляются статистика по логам (среднее время ответа), суммарный размер скачанных данных по IP-адресу, число сработавших алертов за смену.

Пример 1

Создание массива объектов и доступ к полям

Объявить массив из нескольких пользователей и вывести поля каждой записи через индекс и точку. 
let users = [
  { name: "Олег", age: 21, role: "user" },
  { name: "Мария", age: 30, role: "admin" }
];

console.log(users[0].name);   // Олег
console.log(users[0].age);    // 21
console.log(users[1].role);   // admin
Построчное пояснение
let users = [ ... ];Объявляем массив. Каждый элемент в квадратных скобках — объект в фигурных скобках с одинаковыми полями (name, age, role).
users[0].nameБерём первую запись (индекс 0) и читаем её поле name → "Олег".
users[0].ageПоле age первой записи → 21.
users[1].roleВторая запись (индекс 1), поле role → "admin".
Пример 2

Поиск объекта по значению поля

Найти пользователя по имени и вывести его данные. Используем поиск по полю name с break при совпадении. 
let users = [
  { name: "Олег", age: 21, role: "user" },
  { name: "Мария", age: 30, role: "admin" },
  { name: "Пётр", age: 17, role: "user" }
];

let target = "Мария";
let found = -1;

for (let i = 0; i < users.length; i++) {
  if (users[i].name === target) {
    found = i;
    break;
  }
}

console.log(found);
Построчное пояснение
let users = [ ... ]Массив объектов-пользователей.
let target = "Мария";Имя, которое ищем (значение поля name).
let found = -1;Переменная для индекса. -1 — «пока не нашли».
for (let i = 0; i < users.length; i++)Перебираем все записи.
if (users[i].name === target)Сравниваем поле name текущей записи с искомым именем.
found = i; break;Запоминаем индекс и прерываем цикл — нашли первое совпадение.
console.log(found);Выводим индекс найденной записи (1).
Пример 3

Фильтрация по полю age

Отобрать в новый массив только совершеннолетних пользователей (age >= 18). 
let users = [
  { name: "Олег", age: 21 }, { name: "Мария", age: 30 },
  { name: "Пётр", age: 17 }, { name: "Анна", age: 25 }
];

let adults = [];

for (let i = 0; i < users.length; i++) {
  if (users[i].age >= 18) {
    adults.push(users[i]);
  }
}

console.log(adults);
Построчное пояснение
let adults = [];Новый пустой массив для результата.
for (... i < users.length ...)Перебираем все записи исходного массива.
if (users[i].age >= 18)Условие фильтра по полю age: запись проходит, если возраст не меньше 18.
adults.push(users[i]);Добавляем целую запись (объект) в результирующий массив.
console.log(adults);Выводим отфильтрованный массив (3 записи).
Пример 4

Сортировка по полю age

Отсортировать массив объектов по возрасту по возрастанию, используя сортировку пузырьком по полю age. 
let users = [
  { name: "Олег", age: 21 }, { name: "Мария", age: 30 },
  { name: "Пётр", age: 17 }, { name: "Анна", age: 25 }
];

for (let i = 0; i < users.length - 1; i++) {
  for (let j = 0; j < users.length - 1 - i; j++) {
    if (users[j].age > users[j + 1].age) {
      let temp = users[j];
      users[j] = users[j + 1];
      users[j + 1] = temp;
    }
  }
}

console.log(users);
Построчное пояснение
for (let i = 0; i < users.length - 1; i++)Внешний цикл — число проходов сортировки.
for (let j = 0; j < users.length - 1 - i; j++)Внутренний цикл — сравнение соседних записей; граница короче с каждым проходом.
if (users[j].age > users[j + 1].age)Ключевое отличие от чисел: сравниваются поля age соседних записей.
let temp = users[j]; users[j] = users[j+1]; users[j+1] = temp;Обмен местами двух целых объектов через временную переменную.
console.log(users);Выводим отсортированный массив.
