Задача 1

Класс Fraction — работа с дробью

Класс обыкновенной дроби: числитель и знаменатель. Метод toString() возвращает строку вида «a / b», метод asDecimal() — дробь десятичной записью. Оба используют шаблонные строки. 
class Fraction {
  constructor(numer, denom) {
    this.numer = numer;
    this.denom = denom;
  }
  toString() {
    return `${this.numer} / ${this.denom}`;
  }
  asDecimal() {
    return (this.numer / this.denom).toFixed(2);
  }
}

let n = +prompt("Числитель:");
let d = +prompt("Знаменатель:");
let f = new Fraction(n, d);
console.log(`Дробь: ${f.toString()}`);
console.log(`Десятичная: ${f.asDecimal()}`);
Построчное пояснение
constructor(numer, denom)Конструктор сохраняет числитель и знаменатель в поля объекта.
toString() { return \`${this.numer} / ${this.denom}\`; }Метод возвращает читаемую строку дроби через шаблонную строку.
asDecimal() { return (this.numer / this.denom).toFixed(2); }Делит числитель на знаменатель и округляет до двух знаков через toFixed().
let n = +prompt("Числитель:");Унарный + превращает строку из prompt в число.
let f = new Fraction(n, d);Создаём экземпляр дроби.
console.log(\`Дробь: ${f.toString()}\`)Подставляем результат метода в шаблонную строку вывода.
Задача 2

Класс ShoppingCart — корзина покупок

Корзина хранит список позиций в массиве items. Метод add() добавляет товар с ценой, count() возвращает число позиций, total() — общую сумму. 
class ShoppingCart {
  constructor() {
    this.items = [];
  }
  add(name, price) {
    this.items.push({ name, price });
  }
  count() {
    return this.items.length;
  }
  total() {
    let sum = 0;
    for (let i = 0; i < this.items.length; i++) {
      sum += this.items[i].price;
    }
    return sum;
  }
}

let cart = new ShoppingCart();
cart.add("Монитор", 15000);
cart.add("Клавиатура", 3500);
cart.add("Мышь", 1200);
console.log(`В корзине позиций: ${cart.count()}`);
console.log(`Сумма заказа: ${cart.total()} руб.`);
Построчное пояснение
this.items = [];Каждая корзина начинает с пустого массива позиций.
add(name, price) { this.items.push({ name, price }); }Добавляет объект с полями name и price в конец массива.
count() { return this.items.length; }Возвращает число записей — length массива.
total()Проходит по всем позициям и накапливает сумму полей price.
sum += this.items[i].price;Прибавляет цену текущей позиции.
console.log(\`В корзине позиций: ${cart.count()}\`)Вывод количества через шаблонную строку.
Задача 3

Класс Cipher — шифр Цезаря

Класс шифрования Цезаря: приватный сдвиг #shift, метод encode() сдвигает код каждого символа строки и собирает зашифрованный текст. Сдвиг хранится в приватном поле и снаружи не виден. 
class Cipher {
  #shift;
  constructor(shift) { this.#shift = shift; }
  encode(text) {
    let out = "";
    for (let i = 0; i < text.length; i++) {
      out += String.fromCharCode(text.charCodeAt(i) + this.#shift);
    }
    return out;
  }
}

let c = new Cipher(3);
let msg = prompt("Сообщение:");
console.log(`Зашифровано: ${c.encode(msg)}`);
Построчное пояснение
#shift;Приватное поле сдвига — недоступно снаружи класса.
encode(text)Метод шифрования: проходит по каждому символу строки.
text.charCodeAt(i)Получает числовой код символа.
String.fromCharCode(code + this.#shift)Прибавляет сдвиг к коду и превращает обратно в символ.
out += ...Накопление зашифрованной строки.
console.log(\`Зашифровано: ${c.encode(msg)}\`)Вывод результата через шаблонную строку.
Кибербезопасность
Шифр Цезаря — простейший пример замены символов. Он небезопасен для реальной передачи данных, но объясняет принцип сдвига кодов. Модель классов здесь показывает, как скрыть ключ (сдвиг) внутри объекта и дать наружу только метод шифрования.
Задача 4

Наследование: Car extends Transport

Базовый класс Transport (скорость), дочерний Car (марка). Через super() вызывается конструктор родителя, метод describe() переопределяется и включает родительскую часть через super.describe(). 
class Transport {
  constructor(speed) { this.speed = speed; }
  describe() { return `Транспорт, скорость ${this.speed} км/ч`; }
}

class Car extends Transport {
  constructor(brand, speed) {
    super(speed);
    this.brand = brand;
  }
  describe() {
    return `${super.describe()} → автомобиль ${this.brand}`;
  }
}

let car = new Car("Lada", 120);
console.log(`Описание: ${car.describe()}`);
Построчное пояснение
class TransportБазовый класс: поле speed и метод describe().
class Car extends TransportДочерний класс наследует от Transport.
super(speed);Вызов конструктора родителя: записывает this.speed. Идёт первым.
this.brand = brand;Добавляем собственное поле brand.
super.describe()Вызов родительского метода — возвращает строку про «Транспорт».
\`${super.describe()} → автомобиль ${this.brand}\`Склеиваем родительскую часть и собственное поле через шаблонную строку.
Задача 5

Статический метод PasswordGenerator.generate

Класс-генератор паролей со статическим методом generate(length): строит случайную строку из букв и цифр. Статический метод вызывается через имя класса, а не через экземпляр. 
class PasswordGenerator {
  static generate(length) {
    let symbols = "abcdefghijklmnopqrstuvwxyz0123456789";
    let out = "";
    for (let i = 0; i < length; i++) {
      out += symbols[Math.floor(Math.random() * symbols.length)];
    }
    return out;
  }
}

let len = +prompt("Длина пароля:");
console.log(`Сгенерирован пароль: ${PasswordGenerator.generate(len)}`);
Построчное пояснение
static generate(length)Статический метод — принадлежит классу, вызывается как PasswordGenerator.generate(...).
let symbols = "abc...0123456789";Набор символов, из которых строится пароль.
out += symbols[Math.floor(Math.random() * symbols.length)];Случайный индекс умножает Math.random() на длину набора, Math.floor отбрасывает дробь, символ добавляется к строке.
for (let i = 0; i < length; i++)Повторяем ровно length раз, чтобы получить строку нужной длины.
console.log(\`Сгенерирован пароль: ${PasswordGenerator.generate(len)}\`)Вызов статического метода через имя класса.
Кибербезопасность
Случайная генерация пароля — важный приём. Обратите внимание: Math.random() подходит для учебных задач, но не для криптографии. Для настоящих токенов и паролей используют криптографически стойкий crypto.getRandomValues().

Как запускать код

В браузере: код с prompt() запускается в консоли разработчика (F12).
В Node.js: prompt() нет — используйте readline или заранее заданные данные; вывод через console.log и шаблонные строки работает как обычно.
Способ запуска: node имя_файла.js

Классы, приватные поля и шаблонные строки поддерживаются обоими окружениями без настроек.
